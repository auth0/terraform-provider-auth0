# Resource: auth0_organization_client

With this resource, you can manage the association between an organization and an application (client), controlling that application's entitlement to the organization (EA only). This is distinct from `auth0_organization_client_grant`, which associates an organization with a `client_grant` (a client/audience/scopes triple used for client-credentials exchanges).

## Example Usage

```terraform
resource "auth0_organization" "my_organization" {
  name         = "my-organization"
  display_name = "My Organization"
}

resource "auth0_client" "my_client" {
  name = "My Application"
}

# Entitle the application to the organization (EA only). This is distinct
# from `auth0_organization_client_grant`, which associates the organization
# with a client_grant instead of an application.
resource "auth0_organization_client" "my_org_client" {
  organization_id       = auth0_organization.my_organization.id
  client_id             = auth0_client.my_client.id
  use_for_member_access = true
}
```

## Schema

### Required

- `client_id` (String) The ID of the client (application) to associate with the organization.
- `organization_id` (String) The ID of the organization to associate the client (application) with.

### Optional

- `use_for_member_access` (Boolean) Whether this client is used for member access to the organization. An association starts out with this turned off and it has to be activated explicitly.

### Read-Only

- `app_type` (String) The type of the associated client application.
- `grant_types` (List of String) The grant types enabled for the associated client.
- `id` (String) The ID of this resource.
- `is_first_party` (Boolean) Whether the associated client is a first-party client (`true`) or not (`false`).
- `logo_uri` (String) The URI of the associated client's logo.
- `name` (String) The name of the associated client.
- `organization_usage` (String) How the associated client handles organizations during authentication. Available values are `deny`, `allow` or `require`. This is a read-only reflection of the client's own `organization_usage` setting and is managed on the `auth0_client` resource, not here.
