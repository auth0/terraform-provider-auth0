# Data Source: auth0_client_profile

Data source to retrieve a specific Auth0 client profile (application profile) by `id`. This feature is available in Early Access only and requires the `read:client_profiles` scope on the Management API client. (EA only)

## Example Usage

```terraform
# An Auth0 client profile (application profile) can be retrieved by its ID.
data "auth0_client_profile" "my_profile" {
  id = "cpr_XXXXXXXXXXXXXXXXXXXXXX"
}
```

## Schema

### Required

- `id` (String) The ID of the client profile.

### Read-Only

- `apply_policy` (List of Object) Runtime matching rules that determine which clients this profile governs. Defaults to dynamically registered CIMD clients. (see [below for nested schema](#nestedatt--apply_policy))
- `client_configuration` (List of Object) Runtime policy applied to matched clients. Omitted settings fall back to each client's own setting. Auth0 replaces this block as a whole, so removing it clears all of its settings. (see [below for nested schema](#nestedatt--client_configuration))
- `created_at` (String) The ISO 8601 formatted date the client profile was created.
- `description` (String) The description of the client profile. Removing the attribute clears the description in Auth0.
- `name` (String) The name of the client profile.
- `updated_at` (String) The ISO 8601 formatted date the client profile was updated.
