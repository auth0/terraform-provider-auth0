# Resource: auth0_agent

With this resource, you can manage an agent identity (EA only). Link an agent to an application with the `agent_id` attribute of the `auth0_client` resource. Deleting an agent does not delete the clients linked to it and does not clear their `agent_id`, so reference the agent as `auth0_agent.<name>.id` to make Terraform unlink the client before the agent is deleted. The Management API credentials need the `*:agents` scopes. Tenants without the feature enabled respond with `403 not_enabled`.

## Example Usage

```terraform
# Available in Early Access (EA). Requires the tenant to be enabled for agents.
resource "auth0_agent" "my_agent" {
  name              = "My Agent"
  external_agent_id = "my-agent-001"
  metadata = jsonencode({
    team = "platform"
  })
}

# Link the agent to an application. Reference the agent as `auth0_agent.<name>.id`
# so the client is unlinked before the agent is deleted.
resource "auth0_client" "my_agent_client" {
  name     = "My Agent Client"
  app_type = "non_interactive"
  agent_id = auth0_agent.my_agent.id
}
```

## Schema

### Required

- `name` (String) The name of the agent. Must be 1-255 characters and cannot contain `<`, `>` or null characters.

### Optional

- `external_agent_id` (String) An external identifier for the agent. Must be unique within the tenant, 1-128 characters and cannot contain null characters. Changing it forces a new agent to be created.
- `metadata` (String) Arbitrary key-value metadata for the agent, as a JSON object of at most 10240 bytes. Removing the attribute clears the metadata.

### Read-Only

- `created_at` (String) The time the agent was created, in RFC 3339 format.
- `id` (String) The ID of this resource.
- `updated_at` (String) The time the agent was last updated, in RFC 3339 format.
