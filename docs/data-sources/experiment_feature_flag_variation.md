# Data Source: auth0_experiment_feature_flag_variation

Data source to retrieve a specific Experiment Center feature flag variation by `feature_flag_id` and `variation_id`. (EA only)

## Example Usage

```terraform
# An Auth0 Experiment Center feature flag variation loaded using its feature flag ID and variation ID.
data "auth0_experiment_feature_flag_variation" "treatment" {
  feature_flag_id = "flg_XXXXXXXXXXXXXXX"
  variation_id    = "var_XXXXXXXXXXXXXXX"
}
```

### Required

- `feature_flag_id` (String) The ID of the feature flag that owns the variation.

- `id` (String) The ID of this resource.

- `overrides` (Set of Object) Parameter overrides for the variation. Omit for a control variation. Removing an override replaces the variation, because the API cannot remove an override key. (see [below for nested schema](#nestedatt--overrides))
