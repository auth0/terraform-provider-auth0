# Common Pitfalls

## 1. Using `HandleAPIError` instead of `HandleReadAPIError` in Read functions

`HandleAPIError` silently removes the resource from state on 404 with no user-visible warning. `HandleReadAPIError` emits a Terraform warning that explains the removal. Always use `HandleReadAPIError` in `Read` functions:

```go
// ❌ Legacy — avoid in Read functions
return internalError.HandleAPIError(data, err)

// ✅ Correct for Read functions
return internalError.HandleReadAPIError("MyResource", data, err)
```

`HandleAPIError` is kept for backward compatibility in older resources; do not use it in new code.

## 2. Editing `docs/` manually

`docs/` is fully auto-generated by `make docs` (`go generate` → `tfplugindocs`). Any manual edits are overwritten on the next `make docs` run. To change resource documentation, edit:

- Schema `Description` fields in `internal/auth0/<name>/resource.go`
- `templates/` for structural overrides
- `examples/<name>/` HCL files for usage examples

The CI `check-docs` job will fail if `docs/` has uncommitted changes after `make docs`.

## 3. Forgetting to run `make docs` before submitting a PR

Schema changes don't automatically regenerate `docs/`. Always run `make docs` locally after any schema change, then commit the updated `docs/` files in the same PR. CI will catch it if you forget, but it's cleaner to run it locally first.

## 4. Committing cassettes with unredacted secrets

The HTTP recorder at `internal/acctest/http_recorder.go` automatically redacts sensitive values, but always inspect new `test/data/recordings/*.yaml` files before committing. Look for real `AUTH0_DOMAIN` values, client secrets, signing keys, or auth tokens. If found, extend the redaction patterns in `http_recorder.go` rather than editing the cassette manually.

## 5. Not deleting the old cassette before re-recording

`go-vcr` runs in `ModeRecordOnce` — it will not overwrite an existing cassette file. Delete `test/data/recordings/<TestName>.yaml` before running `make test-acc-record FILTER="TestName"`, otherwise the old cassette will still play back.

## 6. Using `data.Get()` instead of `data.GetRawConfig()` in expand functions

`data.Get("field")` returns the zero value for unset optional fields, which can cause the provider to send unwanted zero values to the API, resulting in spurious diffs. Use `data.GetRawConfig()` with `value.String()` / `value.Bool()` helpers from `internal/value/` when you need to distinguish between "not set" and "set to zero value."

## 7. Forgetting `Importer` on new resources

Every new resource should include an importer so users can import existing Auth0 resources into Terraform state:

```go
Importer: &schema.ResourceImporter{
    StateContext: schema.ImportStatePassthroughContext,
},
```

Omit only if the resource genuinely cannot be imported, and document why in the schema description.
