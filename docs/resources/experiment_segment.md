# Resource: auth0_experiment_segment

Create and manage Experiment Center segments (EA only).

## Example Usage

```terraform
# Each rule sets at least one of `match` or `not_match`. Each attribute block
# sets exactly one operator: `one_of`, `contains`, `starts_with`, `ends_with`
# or `exists`. Each `match` or `not_match` block sets between 1 and 10
# attributes, and each `anonymous_session_metadata` block counts as one.
resource "auth0_experiment_segment" "campaign_traffic" {
  name        = "email-campaign-traffic"
  description = "Gold-plan visitors from an email campaign, excluding internal traffic."

  # Omit `status` or set it to "active" on creation. To archive the segment,
  # set it to "archived" in a later apply. Archiving cannot be undone, and
  # `name`, `description` and `rules` cannot change after that.
  # status = "archived"

  rules {
    match {
      country {
        one_of = ["US", "CA"]
      }

      domain {
        starts_with = ["www"]
      }

      device_type {
        contains = ["mobile"]
      }

      client_id {
        exists = true
      }

      # Set one block per metadata key. Use the key without the
      # `anonymous_session_metadata.` prefix.
      anonymous_session_metadata {
        key    = "plan"
        one_of = ["gold"]
      }

      anonymous_session_metadata {
        key      = "utm_source"
        contains = ["email"]
      }
    }

    not_match {
      region {
        ends_with = ["-west"]
      }

      browser {
        ends_with = ["bot"]
      }

      anonymous_session_metadata {
        key    = "internal"
        exists = true
      }
    }
  }

  rules {
    match {
      organization_id {
        exists = true
      }
    }
  }
}
```

## Schema

### Required

- `name` (String) The name of the segment. Unique per tenant. Between 3 and 255 characters
- `rules` (Block List, Min: 1, Max: 20) The rules of the segment. Between 1 and 20 rules. (see [below for nested schema](#nestedblock--rules))

### Optional

- `description` (String) Description of the segment. Between 3 and 1024 characters when present.
- `status` (String) The lifecycle status of the segment. One of "active, archived". A non-`active` status on creation is applied internally after the segment is created as `active`. If the status update fails, Terraform marks the entire resource tainted and plans to replace it on the next apply. Archiving is terminal: an archived segment cannot return to `active`, and its `name`, `description` and `rules` can no longer change. An archived segment can still be deleted and keeps its name reserved until then.

### Read-Only

- `created_at` (String) The ISO 8601 formatted date the segment was created.
- `id` (String) The ID of this resource.
- `type` (String) The type of the segment.
- `updated_at` (String) The ISO 8601 formatted date the segment was updated.

- `starts_with` (List of String) Values for the `starts_with` operator. Between 1 and 50 values, each up to 1024 characters. An empty list counts as not set.
