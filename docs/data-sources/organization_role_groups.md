# Data Source: auth0_organization_role_groups

Data source to retrieve the groups assigned to a specific role within the context of an organization. For the members with a direct role assignment, use `auth0_organization_role_members`. (EA only)

## Example Usage

```terraform
# The groups assigned to an organization-level role.
data "auth0_organization_role_groups" "my_role_groups" {
  organization_id = "org_abcdefghkijklmn"
  role_id         = "rol_abcdefghkijklmn"
}
```
