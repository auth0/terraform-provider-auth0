# Resource: auth0_experiment_feature_flag_variation

Create and manage an Experiment Center feature flag variation (EA only).

## Example Usage

```terraform
resource "auth0_experiment_feature_flag" "my_flag" {
  name        = "checkout-passkey-rollout"
  description = "Feature flag driving the passkey A/B test on the login screen."

  parameters {
    name  = "show_passkey"
    type  = "boolean"
    value = "false"
  }

  parameters {
    name  = "cta_label"
    type  = "string"
    value = "Sign in"
  }

  parameters {
    name = "obj1"
    type = "object"
    value = jsonencode({
      label   = "A"
      enabled = true
    })
  }
}

# A control variation has no overrides, so it serves the flag defaults.
resource "auth0_experiment_feature_flag_variation" "control" {
  feature_flag_id = auth0_experiment_feature_flag.my_flag.id
  name            = "control"
  description     = "Serves the feature flag defaults."
}

# Each override must name a parameter of the feature flag, match its type,
# and differ from its default value. `value` is always a string; use a
# JSON-encoded string when `type` is "object" or "array".
resource "auth0_experiment_feature_flag_variation" "treatment" {
  feature_flag_id = auth0_experiment_feature_flag.my_flag.id
  name            = "passkey-treatment"
  description     = "Shows the passkey enrollment screen."

  overrides {
    name  = "show_passkey"
    type  = "boolean"
    value = "true"
  }

  overrides {
    name  = "cta_label"
    type  = "string"
    value = "Continue with passkey"
  }

  overrides {
    name = "obj1"
    type = "object"
    value = jsonencode({
      label   = "B"
      enabled = true
    })
  }
}
```

## Schema

### Required

- `feature_flag_id` (String) The ID of the feature flag that owns the variation.
- `name` (String) The name of the variation. Must be unique within the feature flag and contain 3 to 255 characters without surrounding whitespace.

### Optional

- `description` (String) Description of the variation. Must contain 3 to 1024 characters when set.
- `overrides` (Block Set) Parameter overrides for the variation. Omit for a control variation. (see [below for nested schema](#nestedblock--overrides))

- `id` (String) The ID of this resource.
- `updated_at` (String) The ISO 8601 formatted date the variation was updated.
- `variation_id` (String) The ID of the variation within its feature flag.
